# PhoneCast VR v0.9.0

Connection feedback, easier receiver discovery, and diagnostics for early-access support.

## What's new

- **Clear phone connection status:** green requires a receiver reply, not merely local screen capture. Unreachable receivers, wrong-address/code failures and reconnects provide actionable guidance.
- **Calmer retries:** failed connection messages stay visible between attempts, with stable status-card sizing instead of flashing Connecting/Disconnected.
- **Find headset on LAN:** a bounded IPv4 search displays running receiver names, addresses and versions. You explicitly select a receiver; pairing and Android screen-sharing consent remain required. Manual IP entry is retained.
- **About on phone and headset:** installed version/build information for support. Android is version 0.9.0, version code 6, signed with the same release key for in-place updates from the release app.
- **Export diagnostics to Downloads:** safe, bounded support summaries on both devices without ADB/SSH. Headset filenames use `phonecast-headset-<timestamp>.txt`.
- **Idle screen-timeout fix:** with Modify system settings access, casting temporarily extends the timeout independently of dimming and restores the original afterward. This resolves the physically reproduced 15-second idle-lock case on the owner's Samsung S22+ / Android 16. Intentional manual locking still ends projection.
- **Hotkey guidance:** the dashboard now explicitly tells users to close it before using stick shortcuts.

## Install or update

Install both v0.9.0 assets to use the new headset About/export and discovery features. Stop phone casting and quit the receiver before updating. Rerun the included receiver installer; saved settings/pairing are retained. Install the APK over the existing release-signed app. Debug-signed installations require the previously documented uninstall/migration procedure.

See the [README](https://github.com/bangfireball/Steam_Frame_Phone_Overlay/blob/v0.9.0/README.md) for installation commands, permissions and troubleshooting.

**Headset log export needs two deliberate selections:** Settings → About / Export logs → select Export logs once to show Confirm export → select the same row again. Wait for Saved to Downloads and the filename. This is not the thumbstick double-click hotkey.

## Validation and remaining limitations

The project owner accepted the revised normal-use UI/support baseline for release. Android debug/release JVM tests (49 each), APK builds and lint pass; all 11 Windows CTest tests pass; ARM64 compilation and QEMU portable/audio/support/runtime tests pass. Signature, archive permissions and live-download checksums are verified.

This remains early-access software, not an exhaustive hardware/network compatibility approval:

- **Trusted LAN only:** transport is not encrypted. Do not expose the receiver publicly.
- Discovery needs same-LAN IPv4 broadcast reachability and UDP 49322. Guest/client isolation, VPN, cross-subnet or IPv6-only networks may require manual IP entry. Stop/search/select/start if an IP changes; active-session identity-based retargeting is not implemented. Multiple-receiver and every blocked-network/storage-failure case were not individually physically witnessed before release acceptance.
- A receiver reply does not prove decoded/visible video. Pairing rejection uses connection closure rather than a distinct wire error, so guidance does not claim a confirmed wrong-code diagnosis.
- Existing Qualcomm decoder freezes and Adreno/Vulkan device-loss failures remain separate reliability work. Recovery, sleep/wake, SteamVR restart, wider game compatibility and both launch orders are not exhaustively validated.
- Force Stop cannot immediately restore brightness, timeout or phone volume; later recovery depends on permissions. Manual locking continues to follow Android privacy rules.
- Settings still uses the floating panel. Dashboard-integrated Settings is assessed but not implemented. Keyboard/text entry, wrist gestures and per-hotkey toggles remain backlogged.

Detailed evidence and boundaries: [v0.9 support work](https://github.com/bangfireball/Steam_Frame_Phone_Overlay/blob/v0.9.0/docs/v0.9-support.md).
